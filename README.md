# NexusAI Pro - 50-in-1 AI Micro-SaaS Platform ⚡

NexusAI Pro is a complete, ready-to-deploy 50-in-1 AI Micro-SaaS suite built with Tailwind CSS, Vanilla JavaScript, and Google Gemini 2.5 Flash API.

## 🚀 Key Features

- **50 AI Micro-Tools:** Categories include Marketing, YouTube/Social, Coding, Business Pitching, and Productivity.
- **5 Pro-Locked Features:** Integrated upgrade modals for Bulk AI, URL Analyzer, PDF Export, History Vault, and Brand Voice.
- **Dual Theme Support:** Dark Mode & Cream-Light Mode with smooth shadow transitions.
- **Zero Backend Required:** Pure client-side edge deployment ready for Vercel, Netlify, or Cloudflare Pages.

## 🛠️ Quick Setup & Deployment

1. **Clone or Download Source:**
   Place `index.html`, `tools.js`, `config.js`, `privacy.html`, and `README.md` in your root folder.

2. **Deploy to Vercel:**
   - Push your project folder to GitHub.
   - Import the repository into Vercel.
   - Click **Deploy**!
